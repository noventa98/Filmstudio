# Security Policy

This is a personal film catalog web app. If you discover a security issue, please report it by opening a GitHub issue:

https://github.com/noventa98/Filmstudio/issues

For sensitive issues, mark the issue title with `[SECURITY]` and I will respond privately if needed.

## Scope

- XSS or injection vulnerabilities in the web app
- Exposure of secrets (API keys, tokens) in committed code
- Flaws in the build script (`build_catalog.py`) that process Excel input

## Out of scope

- Plex server vulnerabilities (report to Plex)
- TMDB/OMDB API vulnerabilities (report to those services)
- Social engineering or phishing
